# 🎵 Lyrics Box

お気に入りの歌詞を投稿・投票できるコミュニティアプリケーション。あなたのお気に入りの歌詞をシェアして、他のユーザーと共有しましょう！

## ✨ 機能

- **📝 投稿画面**: お気に入りの歌詞を投稿できます
  - 歌詞テキストを入力
  - 曲情報（曲名、アーティスト）を登録
  - 簡単な操作で投稿完了

- **🗳️ 投票画面**: 他のユーザーが投稿した歌詞に投票できます
  - おすすめの歌詞に投票
  - 人気ランキングの表示
  - リアルタイムの投票結果確認
